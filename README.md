# 🍞 路边摊自助点餐系统

> 面包 · 饼干 · 鸡尾酒 — 纯前端、零手续费、永久免费

## ✨ 功能

| 功能 | 说明 |
|------|------|
| 📋 **在线菜单** | 分面包/饼干/鸡尾酒三大类，含价格、描述、emoji 图标 |
| 🛒 **购物车** | 支持增减数量、单品备注，右侧滑出面板 |
| 📍 **外卖下单** | 填写配送地址和电话，生成订单文字 |
| 💬 **微信发送** | 一键复制订单内容，发给商家微信 |
| 💳 **线下付款** | 微信转账付款，无任何手续费 |
| ⚙️ **商家后台** | 添加/编辑/删除菜品，修改价格、上下架 |
| 📦 **订单记录** | 所有订单保存在本地，可随时查看 |
| 📱 **点餐二维码** | 自动生成专属二维码，顾客扫码即用 |
| 🎨 **手机适配** | 完美适配各种手机屏幕 |

## 🚀 使用方式

### 方式一：本地打开
直接双击 `index.html` 用浏览器打开即可。

### 方式二：免费静态托管（推荐）

部署到任意免费静态托管平台，获得一个可被扫码访问的链接：

- **GitHub Pages**：推送到 GitHub 仓库 → Settings → Pages → 选 main 分支 → 保存
- **Vercel**：`vercel` 一键部署
- **Netlify**：拖拽 `index.html` 到页面即可

部署后，在页面上点击「📱 点餐码」即可生成专属二维码。

## 🔐 商家后台

- 点击右下角 ⚙️ 齿轮按钮
- 默认密码：**admin888**（请尽快修改）
- 可在后台修改菜单、查看订单、设置店铺信息

## 📱 顾客点餐流程

1. 扫码或打开链接 → 看到菜单
2. 选菜品加入购物车 → 可添加备注
3. 点击结算 → 填写地址和电话
4. 提交订单 → 复制订单文字
5. 打开微信 → 粘贴发送给商家
6. 微信转账付款 → 等待配送

## 🛠 技术说明

- 纯 HTML/CSS/JS 单文件应用
- 数据存于浏览器 localStorage
- 内置轻量 QR 码生成库
- 无需服务器、无需数据库、无需注册
- 零依赖、零费用

## 📝 自定义

所有数据都在你的浏览器中，商家后台可随时修改。如需完全重置，清除浏览器数据即可。
